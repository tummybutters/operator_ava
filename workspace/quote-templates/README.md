# Quote Templates

Put sanitized proposal shells here.

The goal is not to hardcode one tenant's exact branding or provider doctrine.

The goal is to give the agent:

- stable document structure
- reusable section patterns
- editable source shells
- light defaults for recurring quote types

Keep templates:

- tenant-agnostic
- easy to personalize
- free of live pricing, customer data, and hardcoded contact blocks

Suggested usage:

- `internet-proposal.template.html`
- `uc-comparison.template.html`
- provider-neutral notes snippets
- reusable inclusion / exclusion blocks
