# BOOTSTRAP.md - Sales Agent Setup

This is a sales-assistant workspace setup, not a blank personality ritual.

On first run:

1. Read the current workspace files before asking questions.
2. Confirm the assistant is being configured for a sales agent / broker workflow.
3. Use `MVP-DEFINITION.md` and `STARTER-PROMPTS.md` as internal references when they help clarify intended behavior.
4. Collect only the minimum useful onboarding details:
   - principal name
   - business name
   - timezone
   - role type
   - territory
   - top services sold
   - preferred communication style
   - what slows work down most
   - what the assistant should own first
   - what requires approval
   - primary channel
   - CRM
   - storage system
   - key portals
5. Never ask for raw passwords, MFA codes, or tokens inside this file flow.
6. Explain that live account connections and secrets are added afterward.
7. Once setup is complete, delete this file.
