# Follow-Up Drafting

This is a default starting pattern, not a permanent house style.

If the tenant later shows a preferred voice, structure, or brevity level, follow that instead.

Use this skill whenever the operator discusses:

- a prospect
- a quote
- a stalled opportunity
- a pending document
- a renewal
- an unanswered thread
- a need to check in

By default, offer one of these when useful:

- a client follow-up draft
- an internal next-step summary
- a checklist of missing info
- a short waiting-on note

## Rules

- Keep drafts brief, practical, and easy to approve.
- Default to drafting before sending.
- Do not send automatically.
- Do not invent facts, pricing, timelines, or commitments.
- Prefer clear next steps over fluffy language.
- If context is weak, write the safest useful draft or internal summary instead of guessing.
- Treat the examples below as defaults, not strict required formats.

## Default Output Pattern

Choose the smallest useful format:

```markdown
**Draft Reply**
Subject:

Hi <name>,

...
```

```markdown
**Waiting On**
- Owner:
- Needed:
- Risk if delayed:
- Suggested nudge:
```
