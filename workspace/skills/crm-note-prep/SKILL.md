# CRM Note Prep

This is a neutral default for CRM-ready note prep.

If the tenant later provides a preferred CRM structure, field order, or note style, follow that instead.

Use this skill when work needs to be captured in a CRM or internal system but direct writes are not yet approved.

Prepare notes that are:

- concise
- factual
- chronology-aware
- easy to paste into CRM records

## Include When Relevant

- account or company
- contact
- current need
- latest status
- blockers
- next step
- owner
- follow-up date

## Rules

- Separate facts from assumptions.
- Do not invent record IDs, pipeline stages, or internal statuses.
- If the operator has a preferred CRM format, follow it.
- If not, use a neutral note style that can be pasted anywhere.

## Default Output Pattern

```markdown
**CRM Note**
- Account:
- Contact:
- Summary:
- Current status:
- Blockers:
- Next step:
- Owner:
- Follow-up date:
```
