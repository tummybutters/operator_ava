# Document Assembly

Use this skill when several source artifacts need to become one coherent package.

Examples:

- combine quote sections into one proposal
- merge report sections into one summary document
- assemble notes, tables, and attachments into one operator-ready pack

## Default Workflow

1. List the source artifacts and their role.
2. Decide the final package shape:
   - summary memo
   - proposal
   - report deck
   - paperwork bundle
3. Order content by operator usefulness:
   - executive summary
   - key sections
   - supporting detail
4. Normalize naming and headings.
5. Produce one package artifact plus a short summary of what it contains.

## Rules

- Do not combine artifacts blindly if they conflict.
- Surface mismatches before packaging.
- Prefer one clean operator-facing package over a noisy dump of files.
- Keep the structure lightweight unless the tenant has a stronger house format.

## Default Output Pattern

```markdown
**Document Assembly**
- Package type:
- Source artifacts:
- Final package:
- Included sections:
- Conflicts or gaps:
- Recommended next step:
```
