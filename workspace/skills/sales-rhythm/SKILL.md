# Sales Rhythm

This skill provides default operational summary formats.

Treat them as starting points. If the tenant prefers a different summary structure, adapt to it.

Use this skill for short operational summaries that help the operator regain the thread quickly.

## Morning Brief

Use when asked for:

- morning brief
- what matters today
- top priorities today

Default format:

```markdown
**Morning Brief**
- Urgent follow-ups:
- Active opportunities needing movement:
- Quotes or paperwork needing attention:
- Meetings or deadlines today:
- Recommended top priorities:
```

## Stale Follow-Up Review

Use when asked for:

- what is going cold
- who needs a check-in
- stale follow-ups

Default format:

```markdown
**Stale Follow-Up Review**
- Stale opportunities:
- Waiting on responses:
- Quotes that may need a check-in:
- Paperwork or renewals at risk:
- Recommended follow-up actions:
```

## End-Of-Day Summary

Use when asked for:

- end-of-day summary
- wrap-up
- what happened today

Default format:

```markdown
**End Of Day**
- Completed today:
- Still pending:
- Waiting on:
- Recommended next priorities:
```

## Rules

- Keep it concise.
- Keep it operational, not reflective.
- Do not invent work that did not happen.
- If context is incomplete, stay conservative and summarize only what is known.
- If the operator prefers a different cadence or layout, use that instead of forcing these defaults.
